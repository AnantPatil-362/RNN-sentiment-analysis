# RNN for Sentiment Analysis

## Project Overview
This project uses a Recurrent Neural Network (RNN) to classify IMDB movie reviews as positive or negative.

## Technologies Used
- Python
- PyTorch
- Pandas
- Scikit-learn
- NLTK
- Jupyter Notebook

## Project Workflow
1. Load the IMDB movie review dataset.
2. Clean and preprocess the text.
3. Encode sentiment labels.
4. Convert reviews into TF-IDF features.
5. Split the dataset into training and testing sets.
6. Build and train an RNN model.
7. Evaluate the model on test data.

## Dataset
The project uses the IMDB movie reviews dataset. Download the dataset and place `IMDB Dataset.csv` in the appropriate working directory before running the notebook.

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Download and place the dataset in the correct directory.
4. Open the notebook in Jupyter Notebook or JupyterLab.
5. Run the cells in order.

## Project Goal
To explore text preprocessing, neural networks, and sentiment classification using Python and PyTorch.
